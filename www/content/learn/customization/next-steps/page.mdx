# {metadata.title}

The previous guides introduced MedusaGo's different concepts and how you can use them to customize MedusaGo for a realistic use case. You added brands to your application, linked them to products, and queried the linked data. You can also customize the admin dashboard to manage brands, as explained in the [Customize Medusa Admin](!docs!/learn/customization/customize-admin) guides.

The next chapters will cover each of these concepts in depth, with the different ways you can use them, their options or configurations, and more advanced features that weren't covered in the previous guides. While you can start building with MedusaGo, it's highly recommended to follow the next chapters for a better understanding of MedusaGo's fundamentals.

## Where to Find the Concepts

The following chapters cover the concepts the guides used:

- Modules and data models: [Modules](!docs!/learn/fundamentals/modules), [Data Models](!docs!/learn/fundamentals/data-models), and the [Service Factory](!docs!/learn/fundamentals/modules/service-factory) with the methods `MedusaService` generates.
- Workflows: [Workflows](!docs!/learn/fundamentals/workflows), [Compensation Function](!docs!/learn/fundamentals/workflows/compensation-function), [Workflow Hooks](!docs!/learn/fundamentals/workflows/workflow-hooks), and [Execute Nested Workflows](!docs!/learn/fundamentals/workflows/execute-another-workflow).
- API routes: [API Routes](!docs!/learn/fundamentals/api-routes), [Middlewares](!docs!/learn/fundamentals/api-routes/middlewares), [Validation](!docs!/learn/fundamentals/api-routes/validation), and [Protected Routes](!docs!/learn/fundamentals/api-routes/protected-routes).
- Module links and Query: [Module Links](!docs!/learn/fundamentals/module-links), [Link](!docs!/learn/fundamentals/module-links/link), and [Query](!docs!/learn/fundamentals/query).
- Plugins: [Plugins](!docs!/learn/fundamentals/plugins) and [Create a Plugin](!docs!/learn/fundamentals/plugins/create) explain how to package customizations like the Brand Module to reuse them in other applications.

## Useful Guides

The following guides and references are useful for your development journey:

1. [Commerce Modules](!resources!/commerce-modules): Browse the list of Commerce Modules in MedusaGo and their references to learn how to use them.
2. [Medusa CLI](!resources!/medusa-cli): Learn about the commands you used in the guides, such as `db:generate` and `db:migrate`.
3. [Events and Subscribers](!docs!/learn/fundamentals/events-and-subscribers): Learn how to run logic when an event occurs, such as when a product is created.
4. [Scheduled Jobs](!docs!/learn/fundamentals/scheduled-jobs): Learn how to run logic at a repeated interval.
