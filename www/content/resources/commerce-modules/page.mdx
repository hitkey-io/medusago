# {metadata.title}

In this section of the documentation, you'll find guides and references related to Medusa's Commerce Modules.

A Commerce Module provides features for a commerce domain within its service. When you install the MedusaGo application, all Commerce Modules are available out-of-the-box. The MedusaGo application exposes their features in its core API routes to clients.

A Commerce Module also defines data models, representing tables in the database. The Medusa Framework and tools allow you to extend these data models to add custom fields.

## How to Use Modules

The Commerce Modules can be used in many use cases, including:

- MedusaGo Application: The MedusaGo application comes with all Commerce Modules pre-installed and configured. Their commerce features are exposed through REST APIs.
