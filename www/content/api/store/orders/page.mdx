# {metadata.title}

Guest and registered customers can view orders they placed.

These API routes allow customers to view their orders.

## GET /store/orders

**List Logged-in Customer's Orders**

Retrieve the orders of the logged-in customer. The orders can be filtered by fields such as `id`. The orders can also be sorted or paginated.

**Authentication:** cookie session, JWT bearer token.

## GET /store/orders/\{id\}

**Get an Order**

Retrieve an order by its ID. You can expand the order's relations or select the fields that should be returned. This API route doesn't require customer authentication, so that guest customers can view their order confirmation page after placing an order. To restrict access to this API route, refer to the Restrict Order Retrieval guide.

## POST /store/orders/\{id\}/transfer/accept

**Accept Order Transfer**
