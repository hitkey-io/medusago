# {metadata.title}

A shipping option is a way of shipping an item to or from the customer.

During the checkout flow, the customer selects their preferred shipping option to receive their order.

These API routes allow customers to retrieve available shipping options for their context.

## GET /store/shipping-options

**List Shipping Options for Cart**

Retrieve a list of shipping options for a cart. The cart's ID is set in the required `cart_id` query parameter.

The shipping options also be sorted or paginated.

For a shipping option whose `price_type` is `calculated`, the returned `amount` isn't reliable, as its price is computed on the fly by the fulfillment provider. To retrieve its price, use the Calculate Shipping Option Price API route.

**Authentication:** none.

## POST /store/shipping-options/\{id\}/calculate

**Calculate Shipping Option Price**

Calculate the price of a shipping option in a cart. Use this API route for shipping options whose `price_type` is `calculated`, as their price isn't stored but computed on the fly by the associated fulfillment provider against the cart.

If the fulfillment provider fails to calculate the price, this route returns an error.

**Authentication:** none.

**Path parameters**

<TypeList
  types={[
    { name: "id", type: "`string`", optional: false, description: "The shipping option's ID." }
  ]}
/>

**Header parameters**

  types={[

    { name: "x-medusa-locale", type: "`string`", optional: true, description: "The locale in BCP 47 format to retrieve localized content.", example: "en-US" }
  ]}
/>

**Query parameters**

<TypeList
  types={[
    { name: "locale", type: "`string`", optional: true, description: "The locale in BCP 47 format to retrieve localized content.", example: "en-US" },

If a field is prefixed with `+` it will be added to the default fields, using `-` will remove it from the default fields. Without prefix it will replace the entire default fields." }
  ]}

**Request body** (`application/json`)
