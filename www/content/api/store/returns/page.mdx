# {metadata.title}

Customers can request to return items in their order. The admin user then receives and handles the return.

These API routes allows customers to create a return.

## POST /store/returns

**Create Return**

Create a return for an order's items. The admin receives the return and process it from their side. This API route doesn't require customer authentication, so that guest customers can request a return for their orders. To restrict access to this API route, refer to the Restrict Return Creation guide.

**Authentication:** none.

`400`, `401`, `404`, `409`, `422`, `500`: an [error response](/api/store#errors) is returned.

**Emitted events**

- `order.return_requested`: Emitted when a return request is confirmed.
- `order.return_received`: Emitted when a return is marked as received.
