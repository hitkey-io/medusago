# {metadata.title}

A return reason is a possible reason a customer wants to return an item.

Use these API routes when implementing return creation flow in your storefront to allow customers to select their return reason.

## GET /store/return-reasons

**List Return Reasons**

Retrieve a list of return reasons. The return reasons can be sorted or paginated.

**Authentication:** none.

**Header parameters**

<TypeList
  types={[
    { name: "x-publishable-api-key", type: "`string`", optional: false, description: "Publishable API Key created in the Medusa Admin." },
    { name: "x-medusa-locale", type: "`string`", optional: true, description: "The locale in BCP 47 format to retrieve localized content.", example: "en-US" }
  ]}
/>

**Query parameters**

<TypeList
  types={[
    { name: "fields", type: "`string`", optional: true, description: "Comma-separated fields that should be included in the returned data. if a field is prefixed with `+` it will be added to the default fields, using `-` will remove it from the default fields. without prefix it will replace the entire default fields." },
    { name: "offset", type: "`number`", optional: true, description: "The number of items to skip when retrieving a list." },
    { name: "limit", type: "`number`", optional: true, description: "Limit the number of items returned in the list." },
    { name: "order", type: "`string`", optional: true, description: "The field to sort the data by. By default, the sort order is ascending. To change the order to descending, prefix the field name with `-`." },
    { name: "with_deleted", type: "`boolean`", optional: true, description: "Whether to include deleted records in the result." },
    { name: "locale", type: "`string`", optional: true, description: "The locale in BCP 47 format to retrieve localized content.", example: "en-US" }
  ]}
/>

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="cURL" value="curl">

```bash
curl 'http://localhost:9000/store/return-reasons' \
-H 'x-publishable-api-key: {your_publishable_api_key}'
```

  </CodeTab>
</CodeTabs>

**Responses**

<TypeList
  types={[
    { name: "limit", type: "`number`", optional: false, description: "The maximum number of items returned." },

    { name: "return_reasons", type: "`object[]`", optional: false, description: "The list of return reasons.", children: [
        { name: "id", type: "`string`", optional: false, description: "The return reason's ID." },
