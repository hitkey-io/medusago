# {metadata.title}

An admin can invite new users to manage their team. This allows new users to authenticate as admins and perform admin functionalities.

These API routes allow admin users to manage invites.

## GET /admin/invites

**List Invites**

Retrieve a list of invites. The invites can be filtered by fields such as `id`. The invites can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

## POST /admin/invites/accept

**Accept Invite**

Accept an invite and create a new user.
Since the user isn't created yet, the JWT token used in the authorization header is retrieved from the `/auth/user/emailpass/register` API route (or a provider other than `emailpass`). The user can then authenticate using the `/auth/user/emailpass` API route.

**Authentication:** cookie session, JWT bearer token.

**Query parameters**

<TypeList
  types={[
    { name: "token", type: "`string`", optional: false, description: "The invite's token." },
    { name: "fields", type: "`string`", optional: true, description: "Comma-separated fields that should be included in the returned data. If a field is prefixed with `+` it will be added to the default fields, using `-` will remove it from the default fields. Without prefix it will replace the entire default fields." }
  ]}
/>

**Request body** (`application/json`)

<TypeList
  types={[
    { name: "email", type: "`string`", optional: true, description: "The invite's email." },
    { name: "first_name", type: "`string`", optional: true, description: "The invited user's first name." },
    { name: "last_name", type: "`string`", optional: true, description: "The invited user's last name." }
  ]}
/>

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="JS SDK" value="js-sdk">

```ts
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

await sdk.auth.register("user", "emailpass", {
  email: "user@gmail.com",
  password: "supersecret"
})

// all subsequent requests will use the token in the header
const { user } = await sdk.admin.invite.accept(
  {
    email: "user@gmail.com",
    first_name: "John",
    last_name: "Smith",
    invite_token: "12345..."
  },
)
```

  </CodeTab>
  <CodeTab label="cURL" value="curl">

```bash

-H 'Content-Type: application/json' \
--data-raw '{
  "email": "Lila_Zemlak@hotmail.com",
  "first_name": "{value}",
  "last_name": "{value}"
}'
```

  </CodeTab>
</CodeTabs>

**Responses**

`200` OK

<TypeList
  types={[
    { name: "user", type: "`object`", optional: true, description: "The user's details.", children: [
        { name: "id", type: "`string`", optional: false, description: "The user's ID." },
        { name: "email", type: "`string`", optional: false, description: "The user's email." },

        { name: "created_at", type: "`string`", optional: false, description: "The date the user was created." },
        { name: "updated_at", type: "`string`", optional: false, description: "The date the user was updated." },
