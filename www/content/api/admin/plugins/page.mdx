# {metadata.title}

A plugin is a package of reusable Medusa customizations that you can install in any MedusaGo application.
Plugins can be used to add new functionality, such as wishlists, or integrate third-party services, such as payment providers.
These API routes allow admin users to retrieve plugins installed in their MedusaGo application.

## GET /admin/plugins

**List Plugins**

Retrieve the list of plugins installed in the MedusaGo application.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="JS SDK" value="js-sdk">

```ts
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.plugin.list()
.then(({ plugins }) => {
  console.log(plugins)
})
```

  </CodeTab>
  <CodeTab label="cURL" value="curl">

```bash
curl 'http://localhost:9000/admin/plugins' \
-H 'Authorization: Bearer {jwt_token}'
```

  </CodeTab>
</CodeTabs>

**Responses**

`200` OK
