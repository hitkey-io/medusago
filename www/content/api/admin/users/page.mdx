# {metadata.title}

A user is an admin user that can authenticate and perform functionalities as an admin user.

An admin user can invite other users to join their team. Once they accept the invite, they'll become admin users as well.

These API routes allow admin users to manage their team.

## GET /admin/users

**List Users**

## POST /admin/users/\{id\}/reset-password

**Generate Reset Password Token for a User**

Generate a reset password token for a user. This is useful if another user wants to reset the password of a user. The reset password token can be used to reset the user's password. This route only emits the `auth.password_reset` event. You can listen to this event to send a reset password email to the user, for example.

**Authentication:** cookie session, JWT bearer token.

**Path parameters**

<TypeList
  types={[
    { name: "id", type: "`string`", optional: false, description: "The user's ID." }
  ]}
/>

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="JS SDK" value="js-sdk">

```ts

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",

  auth: {
    type: "session",
  },
})

sdk.admin.user.generateResetPasswordToken("user_123")
.then(({ token }) => {
  console.log(token)
})
```

  </CodeTab>
  <CodeTab label="cURL" value="curl">

```bash
curl -X POST 'http://localhost:9000/admin/users/{id}/reset-password' \
-H 'Authorization: Bearer {access_token}'
```

  </CodeTab>
</CodeTabs>

**Responses**

`200` OK

<TypeList
  types={[
    { name: "token", type: "`string`", optional: false, description: "The generated reset password token. Append it to the admin's\n`/reset-password` page as a `token` query parameter to build a link the\nuser can open to set a new password.\n\nThe token is short-lived, can only be used once, and generating it\ninvalidates any reset password token previously issued for the user." }
  ]}
/>

`400`, `401`, `404`, `409`, `422`, `500`: an [error response](/api/admin#errors) is returned.

**Emitted events**

- `auth.password_reset`: Emitted when a reset password token is generated. You can listen to this event to send a reset password email to the user or customer, for example.
