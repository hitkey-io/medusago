# {metadata.title}

A payment collection is one or more payments of an order. They're also used for outstanding payments due to order exchanges or claims.

Every purchase or request for payment starts with a payment collection.

A payment collection holds the payment sessions used to authorize the payment amount, and the payments to be captured / refunded.

These API routes allow admin users to manage payment collections.

## POST /admin/payment-collections

**Create Payment Collection**

Create a payment collection.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

## POST /admin/payment-collections/\{id\}/mark-as-paid

**Mark a Payment Collection as Paid**

Mark a payment collection as paid. This creates and authorizes a payment session, then capture its payment, using the manual payment provider.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Path parameters**

<TypeList
  types={[
    { name: "id", type: "`string`", optional: false, description: "The payment collection's ID." }
  ]}
/>

<TypeList

    { name: "fields", type: "`string`", optional: true, description: "Comma-separated fields that should be included in the returned data. if a field is prefixed with `+` it will be added to the default fields, using `-` will remove it from the default fields. without prefix it will replace the entire default fields." }
  ]}
/>

**Request body** (`application/json`)

<TypeList
  types={[
    { name: "order_id", type: "`string`", optional: false, description: "The ID of the order associated with the payment collection." },
