# {metadata.title}

A product collection organizes products into a collection for marketing purposes. For example, a summer collection.

These API routes allow admin users to manage collections and the products in them.

## GET /admin/collections

**List Collections**

Retrieve a list of collections. The collections can be filtered by fields such as `id`. The collections can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.
