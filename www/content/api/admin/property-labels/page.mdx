## GET /admin/property-labels

**List Property Labels**

Retrieve a list of property labels. The property labels can be filtered by fields such as `id`. The property labels can also be sorted or paginated.

<Note title="Feature flag">

This API route is only available when the `view_configurations` feature flag is enabled. Set the `MEDUSA_FF_VIEW_CONFIGURATIONS` environment variable to `true` to enable it.

</Note>

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Query parameters**

<TypeList
  types={[
    { name: "entity", type: "`string`", optional: true, description: "The property label's entity." },
    { name: "property", type: "`string`", optional: true, description: "The property label's property." },
    { name: "q", type: "`string`", optional: true, description: "The property label's q." },
    { name: "limit", type: "`number`", optional: true, description: "Limit the number of items returned in the list." },
    { name: "offset", type: "`number`", optional: true, description: "The number of items to skip when retrieving a list." },
    { name: "order", type: "`string`", optional: true, description: "The field to sort the data by. By default, the sort order is ascending. To change the order to descending, prefix the field name with `-`." },
    { name: "with_deleted", type: "`boolean`", optional: true, description: "The property label's with deleted." },
    { name: "fields", type: "`string`", optional: true, description: "Comma-separated fields that should be included in the returned data. If a field is prefixed with `+` it will be added to the default fields, using `-` will remove it from the default fields. Without prefix it will replace the entire default fields." }
  ]}
/>

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="cURL" value="curl">

```bash

-H 'Authorization: Bearer {access_token}'
```

  </CodeTab>
</CodeTabs>

**Responses**

<TypeList
  types={[
    { name: "property_labels", type: "`object[]`", optional: false, description: "TThe list of property labels.", children: [
        { name: "id", type: "`string`", optional: false, description: "The property label's ID." },
        { name: "entity", type: "`string`", optional: false, description: "The entity the property label belongs to." },
        { name: "property", type: "`string`", optional: false, description: "The property the label is associated with." },
        { name: "label", type: "`string`", optional: false, description: "The label for the property." },
        { name: "description", type: "`string`", optional: true, description: "The property label's description." },
        { name: "created_at", type: "`string`", optional: false, description: "The date the property label was created." },
        { name: "updated_at", type: "`string`", optional: false, description: "The date the property label was last updated." }
      ] },
    { name: "count", type: "`number`", optional: false, description: "The total number of property labels." },
    { name: "offset", type: "`number`", optional: false, description: "The number of items skipped before retrieving the returned items." },
    { name: "limit", type: "`number`", optional: false, description: "The maximum number of items returned." }
