# {metadata.title}

A campaign is a group of promotions that have the same conditions, such as start and end dates.

These API routes allow admin users to manage campaigns, their conditions, and promotions that belong to them.

## GET /admin/campaigns

**List Campaigns**

Retrieve a list of campaigns. The campaigns can be filtered by fields such as `id`. The campaigns can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.
