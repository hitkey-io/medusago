# {metadata.title}

An admin can modify the layout of their admin dashboard. This allows admins to customize their dashboard to their preferences and needs.
These API routes allow admin users to manage layouts.

## GET /admin/layouts/configurations

**List Layout Configurations**

Retrieve a list of layout configurations made by admin users. The layouts can be filtered by fields such as `id`. The layouts can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

## DELETE /admin/layouts/\{zone\}/configuration

**Clear Configuration of Layout**

Clears all user layout configurations for a given zone. This action will remove any customizations made by the user and revert to the system defaults.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Path parameters**

<TypeList
  types={[
    { name: "zone", type: "`string`", optional: false, description: "The zone for which the layout configuration should be cleared." }
  ]}
/>

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="cURL" value="curl">

```bash
curl -X DELETE 'http://localhost:9000/admin/layouts/{zone}/configuration' \
-H 'Authorization: Bearer {access_token}'
```

  </CodeTab>
</CodeTabs>

**Responses**

`200` OK

<TypeList
  types={[
    { name: "success", type: "`boolean`", optional: false, description: "Whether the layout configuration was successfully cleared." }
  ]}
/>

`400`, `401`, `404`, `409`, `422`, `500`: an [error response](/api/admin#errors) is returned.
