# {metadata.title}

A translation is a localized version of content in a specific locale. For example, a product description in French.
These API routes allow admin users to manage translations for different locales and resources.

## GET /admin/translations

**List Translations**

Retrieve a list of translations. The translations can be filtered by fields such as `reference_id` (For example, the ID of a product). The translations can also be sorted or paginated.

<Note title="Feature flag">

This API route is only available when the `translation` feature flag is enabled. Set the `MEDUSA_FF_TRANSLATION` environment variable to `true` to enable it.

</Note>

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.
