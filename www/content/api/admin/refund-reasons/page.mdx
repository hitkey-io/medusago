# {metadata.title}

A refund reason is a possible reason used when issuing a refund to the customer, such as when returning an item and refunding the customer.

These API routes allow admin users to manage refund reasons.

## GET /admin/refund-reasons

**List Refund Reasons**

Retrieve a list of refund reasons. The refund reasons can be filtered by fields such as `id`. The refund reasons can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Query parameters**
