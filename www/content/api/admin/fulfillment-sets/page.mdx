# {metadata.title}

A fulfillment set is a general form or way of fulfillment, such as "shipping" or "pick up".

All fulfillment-related configurations in a store are related to a fulfillment set.

These API routes allow admin users to manage fulfillment sets.

## DELETE /admin/fulfillment-sets/\{id\}

**Delete Fulfillment Set**

Delete a fulfillment set.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Path parameters**

<TypeList
  types={[
    { name: "id", type: "`string`", optional: false, description: "The fulfillment set's ID." }
  ]}
/>

**Request examples**

export const sdk = new Medusa({

  debug: import.meta.env.DEV,
