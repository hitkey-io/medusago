# {metadata.title}

An admin creates a claim for an order when a customer reports that an item is defective or incorrect.

Using these API routes, admin users manage order claims, their items, and more.

## GET /admin/claims

Retrieve a list of claims. The claims can be filtered by fields such as `id`. The claims can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.
