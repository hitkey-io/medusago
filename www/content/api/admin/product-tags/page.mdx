# {metadata.title}

A tag is another way of organizing a product. Each tag has a name and a value.

Products are organized into the same tag if they have the same value.

These API routes allow admin users to manage product tags.

## GET /admin/product-tags

**List Product Tags**

Retrieve a list of product tags. The product tags can be filtered by fields such as `id`. The product tags can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.
