# {metadata.title}

A store holds the main configuration and information of your commerce store, such as supported currencies or default sales channel.

By default, the MedusaGo application has one default store. There are no API routes to create more stores. Instead, you'd have  to handle that customization manually.

These API routes allow admin users to manage their store.

## GET /admin/stores

**List Stores**

Retrieve a list of stores. The stores can be filtered by fields such as `id`. The stores can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.
