# {metadata.title}

A locale is a language that content is translated into for customers to view in a storefront.
Medusa installs locales by default. These API routes allow admin users to retrieve and view locales.

## GET /admin/locales

**List Locales**

Retrieve a list of locales. The locales can be filtered by fields such as `code`. The locales can also be sorted or paginated.

<Note title="Feature flag">

This API route is only available when the `translation` feature flag is enabled. Set the `MEDUSA_FF_TRANSLATION` environment variable to `true` to enable it.

</Note>

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

## GET /admin/locales/\{code\}

**Get a Locale**

Retrieve a locale by its code. You can expand the locale's relations or select the fields that should be returned.

<Note title="Feature flag">

This API route is only available when the `translation` feature flag is enabled. Set the `MEDUSA_FF_TRANSLATION` environment variable to `true` to enable it.

</Note>

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Path parameters**

<TypeList
  types={[
    { name: "code", type: "`string`", optional: false, description: "The locale's code in [BCP 47 format](https://gist.github.com/typpo/b2b828a35e683b9bf8db91b5404f1bd1)." }
  ]}
/>

**Query parameters**

<TypeList
  types={[
    { name: "fields", type: "`string`", optional: true, description: "Comma-separated fields that should be included in the returned data. If a field is prefixed with `+` it will be added to the default fields, using `-` will remove it from the default fields. Without prefix it will replace the entire default fields." }
  ]}
/>

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="JS SDK" value="js-sdk">

import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
