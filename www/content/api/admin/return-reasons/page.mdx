# {metadata.title}

A return reason is a possible reason that an item is returned from the customer, such as when returning an item.

These API routes allow admin users to manage return reasons.

## GET /admin/return-reasons

**List Return Reasons**

Retrieve a list of return reasons. The return reasons can be filtered by fields such as `id`. The return reasons can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.
