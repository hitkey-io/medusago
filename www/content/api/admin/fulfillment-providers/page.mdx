# {metadata.title}

A fulfillment provider is a third-party integration or custom logic used to  fulfill an order's items.

Fulfillment providers are installed as module providers.

## GET /admin/fulfillment-providers

**List Fulfillment Providers**

Retrieve a list of fulfillment providers. The fulfillment providers can be filtered by fields such as `id`. The fulfillment providers can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Query parameters**

<TypeList
  types={[

    { name: "offset", type: "`number`", optional: true, description: "The number of items to skip when retrieving a list." },
    { name: "limit", type: "`number`", optional: true, description: "Limit the number of items returned in the list." },

## GET /admin/fulfillment-providers/\{id\}/options

**List Fulfillment Options**

Retrieve the list of fulfillment options of a fulfillment provider. These options may be retrieved from an integrated third-party service.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Path parameters**

<TypeList
  types={[
    { name: "id", type: "`string`", optional: false, description: "The fulfillment provider's ID." }
  ]}
/>

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="JS SDK" value="js-sdk">

```ts
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",

sdk.admin.fulfillmentProvider.listFulfillmentOptions("fp_123")
```
