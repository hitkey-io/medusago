# {metadata.title}

A tax region is a region's tax settings. It has tax rates and rules. So, after you create a region, you must create a tax region for it.

A tax region can extend settings from a parent tax region.

These API routes allow admin users to manage tax regions.

## GET /admin/tax-regions

**List Tax Regions**

Retrieve a list of tax regions. The tax regions can be filtered by fields such as `id`. The tax regions can also be sorted or paginated.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

## POST /admin/tax-regions

**Create Tax Region**

Create a tax region.

**Authentication:** secret API key (HTTP Basic authorization), cookie session, JWT bearer token.

**Query parameters**

<TypeList
  types={[
    { name: "fields", type: "`string`", optional: true, description: "Comma-separated fields that should be included in the returned data. if a field is prefixed with `+` it will be added to the default fields, using `-` will remove it from the default fields. without prefix it will replace the entire default fields." }
  ]}
/>

**Request body** (`application/json`)

<TypeList
  types={[
    { name: "country_code", type: "`string`", optional: false, description: "The tax region's country code.", example: "us" },
    { name: "province_code", type: "`string`", optional: true, description: "The tax region's ISO 3166-2 province code. Must be lower-case.", example: "us-ca" },
    { name: "parent_id", type: "`string`", optional: true, description: "The ID of the parent tax region." },
    { name: "default_tax_rate", type: "`object`", optional: true, description: "The tax region's default tax rate.", children: [
        { name: "rate", type: "`number`", optional: true, description: "The rate to charge.", example: "10" },
        { name: "code", type: "`string`", optional: false, description: "The code the tax rate is identified by" },
        { name: "name", type: "`string`", optional: false, description: "The default tax rate's name.", example: "VAT" },
        { name: "is_combinable", type: "`boolean`", optional: true, description: "Whether the tax rate should be combined with parent rates." },
        { name: "metadata", type: "`object`", optional: true, description: "The default tax rate's metadata, used to store custom key-value pairs. Learn more in the [Manage Metadata](/api/admin#manage-metadata) section." }
      ] },
    { name: "metadata", type: "`object`", optional: true, description: "The tax region's metadata, used to store custom key-value pairs. Learn more in the [Manage Metadata](/api/admin#manage-metadata) section." },
    { name: "provider_id", type: "`string`", optional: true, description: "The ID of the tax provider used to calculate the tax rate in this tax region." }
  ]}
/>

**Request examples**

<CodeTabs group="api-sample">
  <CodeTab label="JS SDK" value="js-sdk">

```ts

  "parent_id": "{value}",
  "metadata": {}
}'
```

  </CodeTab>
</CodeTabs>
